## Shared understanding (grill close-out)

1. **Pre-action section** (Advanced-collapsed, per-Quick-Action, optional). Two fields: **Pre-action check** (required once section used; free-form shell command, same shell+cwd as the Action, timeboxed like Test, exit 0 = pass, changes nothing — e.g. `node --version`, `Test-Path .\config.json`, API-key presence) + **Fix (optional)** (offered only when check fails; e.g. `npm install`, `winget install OpenJS.NodeJS`). Run-click runs check first; fail = warn dialog with check output + `[Run fix]` (only if fix present) / `[Run anyway]` / `[Cancel]`. Fix runs once on click, logged to the same `output.log` with a header, never silent, never elevated. Check-only with no fix is valid (e.g. unfilled variables that need manual editing — early clear error beats digging logs).
2. **Logs reorder only.** `src/routes/logs/+page.svelte:197-214` goes 1. Quick Launch runs 2. Quick Action runs 3. Run folders (preset/program runs). Mirrors tab usage (launch → action → program/plan). No rename, no persistence/disclosure change.
3. **Companion:** follow in-pane navigation; reload/retry always returns to the saved address; site switch replaces at the new saved address with its identity/zoom (existing 166/170 lifecycle); Back/Forward added as the only history chrome. Routing freeze (button does nothing / page fails) stays evidence-gathering in 171 — no speculative navigation/new-window policy in this round.
4. **Image Clips v1:** image-only Clip (name + image, no text content). Creation via paste/file-picker; PNG+JPEG normalized, 5MB cap, one image per Clip. New `clip_images(clip_id, mime, bytes)` table. List shows thumbnail; row/details shows name + rendered image in main app and dock; dock/main click copies image (image-clipboard path, distinct from text `copyClip`). Backup carries bytes; text-clip dedup/Groups rules untouched.
5. **Action files + `<FilesDir>` placeholder contract:** separate `quick_action_files(action_id FK CASCADE, filename, bytes)` table; Action delete cascades, per-file remove deletes one row. Command references files only via `<FilesDir>` placeholder, expanded at run time to a per-run staged dir, shell-quoted by the Windows execution owner. No placeholder = files inert + "unused files" hint. Filenames basename-only, unique per action; 5MB/file, 20MB/action v1 caps. Export: no files = same single JSON as 160; with files = zip bundle (JSON + files/). Whole-app backup extends the same document additively.
6. **Editor (command box):** lightweight coloring for the Action's shell (PowerShell/CMD) + `<` autocomplete for `<FilesDir>` and attached filenames after `<FilesDir>\`. Insert affordance + unused/missing hints. No full IDE/Monaco in this round.

Research may overturn any of the above on architecture / maintainability / scalability / UI-UX grounds; overturns land as spec amendment + dated ADR amendment where a decision changes, in the same unit of work.
