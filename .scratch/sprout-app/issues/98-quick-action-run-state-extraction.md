# 98 — Quick Action run state: one store + one control behind both surfaces

**What to build:** Ticket 94 gave the Quick Actions page the window's Run / Stop / Stopping vocabulary by copying it. Extract the twin copies into one home: a shared `quickActionRuns.svelte.ts` store (running/stopping sets, event subscription, registry seed, stop lifecycle) and a shared `QuickActionRunControl.svelte` (the three-state control markup, spinner styles, aria verbs). Both surfaces — the Quick Actions page rows and the Quick Launch window's Actions tab — render through them, so the vocabulary can no longer drift between files. Launch-entry rows keep their distinct Start-only affordance (fire-and-forget by design; out of scope).
